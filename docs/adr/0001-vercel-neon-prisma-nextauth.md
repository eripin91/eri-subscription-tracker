# Vercel Hobby + Neon Free + Prisma + NextAuth for MVP

Shareable web MVP must cost $0 and stay portable to paid SaaS. We decided on Next.js on Vercel Hobby with serverless Postgres on Neon Free, accessed via Prisma, with NextAuth for email + Google, because Supabase Auth would lock auth to one vendor while Neon keeps Postgres portable to any host.
